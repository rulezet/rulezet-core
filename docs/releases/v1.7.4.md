This release is anchored by a full **Bundles overhaul** — versioned releases, a pre-deployment health check, notes and known issues, private share links and a much richer API — and brings three new features: **Alerts** (watch a search, get notified when new rules match), **multi-provider AI** (Claude, ChatGPT and OpenAI-compatible gateways next to Ollama, with encrypted keys and a monthly budget) and **OIDC / SSO** login. Under the hood, production now runs behind gunicorn with a separate background worker, an optional nginx reverse proxy and Redis cache, and a new test suite written feature by feature found and fixed **105 bugs**, several of them security issues.

Online version available at [rulezet.org](https://rulezet.org/)

---

## Security

- Account takeover through the email verification code is fixed
- Stored XSS through profile links is fixed
- `/rule/update_lock` now requires authentication
- `POST /bundle/delete` without an id no longer deletes bundle #1
- Deleting the tag family `%` no longer wipes every namespaced tag
- "Redirect back" only follows a local path
- Users get neutral error messages; the details only go to the server log
- Regexes applied to user input no longer backtrack
- GitHub import: the clone path and the branch name are validated
- Comments follow the visibility of what they are attached to (private bundle, draft blog post, trashed rule)
- Logging out really ends a "remember me" login
- The SMTP password is no longer written to the log in debug mode
- GitHub rate-limit status is admin-only, and several server IP leaks are closed
- The CI test workflow runs with a read-only token

We recommend every self-hosted instance upgrade as soon as possible.

## New: Bundles Overhaul

- **Detail page redone** — file viewer, files panel, paginated history, private share links
- **Versioned releases** — frozen snapshots of a bundle, compare two releases, release view
- **Health check** — a pre-deployment Health tab with "Fix it for me" actions
- **Notes / known issues** — @mentions, #references to rules and files, curated tags, search, filters, pagination
- Favorites, workspace bundle collections, a **Bundles** tab on the rule page, and AI analysis of a whole bundle
- **Bundle API** — an API key acts as its owner; new detail / rules / structure endpoints, tree-aware add / remove, partial edit; share key sent in an `X-Share-Key` header
- Bundle names are unique per user, and a bundle's owner can rebuild its structure

---

## New: Alerts

Save a search and get told when new rules match it:

- Matching engine with a periodic sweeper, started automatically with the app
- My alerts, an alert builder and a detail page, plus "watch" entry points across the site
- Alert emails with an anti-spam protocol: per-user and per-instance ceilings that defer matches, never drop them (`ALERT_*` settings in `config.py`)

---

## New: Multi-Provider AI

- Ollama, **Claude**, **ChatGPT** and any **OpenAI-compatible** gateway as AI providers
- Provider API keys are stored encrypted (`AI_SECRETS_KEY`), with a monthly budget per provider
- In-depth rule analysis, and analysis runs over the whole catalog
- The Ollama server is configurable from the admin

---

## New: OIDC / SSO

Log in through your organisation's identity provider. Enabled from the admin settings and the `OIDC_*` variables; IdP groups map to Rulezet roles (`OIDC_GROUP_ADMIN`, `OIDC_GROUP_EDITOR`).

## Performance & Production

- Production is served by **gunicorn**; the background worker runs as its own process
- Optional **nginx** reverse proxy: API on its own process, separate logs, per-IP rate limiting (`deploy/README.md`)
- Flask-Caching with memory + filesystem caches and an optional **Redis** backend
- `pg_trgm` index on CVEs, batched queries in the rule lists
- Rulesets mirror incremental sync: from days to minutes
- No more background polling for notifications
- New `manage.py restart-prod`

## Tests

A new test suite in `tests_new/`, organised by feature — access per role, CRUD checked in the database, API with a key per role, robustness — runs in CI next to the existing one. Writing it fixed **105 bugs** (rules 21, bundles 21, account 15, tags 14, rule formats 9, MISP 9, ATT&CK 8, comments 8, …).

## Upgrading

`python3 manage.py deploy` (or `update`) handles the code, the new `pivotick-converters` submodule, the new Python dependencies (`anthropic`, `openai`, `authlib`, `Flask-Caching`, `redis`) and the database migrations. Before restarting:

- Set `AI_SECRETS_KEY` in `.env` (see `.env_default`) **before** saving any AI provider key — otherwise `SECRET_KEY` is used, and changing it later makes the stored keys unreadable
- Optional: `OIDC_*`, `YARA_ADDITIONAL_EXTERNAL`, `CACHE_*` / Redis, nginx (`deploy/`)
