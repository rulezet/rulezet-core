Tag Suggestions

Proposes taxonomy and galaxy tags for a rule being written. A token trie built from the useful tag families finds the candidates instantly (no AI), then the model keeps the relevant ones and says why — it can only pick from that list, and nothing is added until the user clicks. Triggered from the "Suggest tags" button under the tag picker on the rule create / edit pages, not from here.
