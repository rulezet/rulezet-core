How edit proposals work
1
Find a rule

Open any rule and go to its Suggest an edit tab.

2
Propose your change

Edit the content, pick a type (typo, security fix…) and explain why. The syntax is checked before it is sent.

3
Discuss & revise

The owner is notified. Everyone can comment on the diff; a proposal can be revised into a new version (v2, v3…).

4
Merge

The owner (or an admin) accepts: the rule gets a new version, credited to you in its history.

Statuses
pendingWaiting for the rule owner's review.
acceptedMerged into the rule as a new version.
rejectedDeclined — the reason, if any, is shown in the details. It can still be revised.
supersededClosed automatically: another version of the same thread was accepted.
